Rubrica помогает держать семестр под контролем. Она показывает ближайшие пары и дедлайны, хранит конспекты, наводит порядок в учебных файлах, помогает повторять материал и собирает отчёты Word по ГОСТ. Всё работает локально, а учебные данные остаются на вашем компьютере.

## Что умеет Rubrica

| Раздел | Возможности |
| --- | --- |
| **Дашборд** | Пары на сегодня, ближайшие дедлайны, недавние заметки и файлы, быстрые действия и прогресс учёбы |
| **Органайзер** | Расписание по неделям, семестры, предметы, календарь дедлайнов, зачётка и прогноз итоговых оценок |
| **Заметки и файлы** | Markdown-конспекты, изображения и рисунки, отдельное пространство для каждого предмета |
| **Архивариус** | Автоматическая сортировка файлов по вашим правилам, предпросмотр результата, журнал действий и отмена перемещения |
| **Картотека** | Колоды и теги, карточки с Markdown, интервальное повторение, режим экзамена, статистика, импорт и экспорт |
| **Отчёты** | Создание `.docx` из текста, заметок или карточек, оформление по ГОСТ 7.32-2017 и собственные профили |

Ещё в приложении есть напоминания о парах, дедлайнах и повторении карточек, тихие часы, быстрый поиск по картотеке, светлая и тёмная темы, автозапуск и резервные копии.

## Как начать

1. [Скачайте установщик Rubrica-win-Setup.exe](https://github.com/LynxSir/StudComp/releases/latest/download/Rubrica-win-Setup.exe).
2. Запустите его и дождитесь окончания установки.
3. При первом запуске выберите учебную папку и создайте семестр.

Поддерживаются 64-битные Windows 10 и Windows 11. Устанавливать .NET отдельно не нужно, всё необходимое уже входит в комплект.
