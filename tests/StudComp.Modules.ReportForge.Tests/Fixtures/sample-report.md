# Введение

Отчёт подготовлен в **Rubrica** — приложении, которое собирает `.docx` по ГОСТ 7.32-2017.
Текст абзаца намеренно содержит *курсив*, ~~зачёркнутое~~ и [ссылку](https://example.com/rubrica).

## Постановка задачи

Требуется проверить, что генератор переносит в документ все виды блоков.

### Проверяемые блоки

- заголовки трёх уровней
- абзацы с начертаниями
  - вложенный пункт списка
- таблицы, изображения и листинги

Порядок проверки:

1. Разобрать markdown в модель документа.
2. Отрендерить модель в пакет OOXML.
3. Прогнать результат через схемную валидацию.
